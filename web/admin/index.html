Login Discord (OAuth)

Aktifkan login Discord di aplikasi
Harus sama persis dengan yang didaftarkan di Discord Developer Portal → OAuth2 → Redirects. Endpoint login web: https://piercingblow.ai.id/auth/discord (default). Jangan pakai URL lama (https://piercingblow.ai.id/) — Discord menolaknya kalau tidak terdaftar. Kosong = otomatis pakai endpoint yang benar. Secret disimpan di server (KV) dan tidak pernah dikirim ke browser user.

API Bot Discord (Verifikasi Akun)

Endpoint ini dipanggil oleh Bot Discord untuk memverifikasi apakah member Discord telah login/terhubung di web, serta memeriksa tier dan kuota tokennya.

GET https://piercingblow.ai.id/api/bot/verify?discord_id=123456789012345678
Header (jika Bot API Key diset): X-Bot-Key: <kunci>
Lihat contoh kode bot (JavaScript & Python)
// discord.js (v14)
const res = await fetch(`https://piercingblow.ai.id/api/bot/verify?discord_id=${interaction.user.id}`, {
  headers: { 'X-Bot-Key': 'KUNCI_BOT' }
});
const data = await res.json();
if (data.verified) {
  await interaction.reply(`Akun terverifikasi! Tier: ${data.user.tier}, Sisa token: ${data.user.tokenRemaining}`);
} else {
  await interaction.reply('Silakan login di web terlebih dahulu!');
}

# discord.py
import aiohttp
async with aiohttp.ClientSession() as session:
  async with session.get(f"https://piercingblow.ai.id/api/bot/verify?discord_id={ctx.author.id}", headers={"X-Bot-Key": "KUNCI_BOT"}) as r:
    data = await r.json()
    if data.get("verified"):
      await ctx.send(f"Terverifikasi! Tier: {data['user']['tier']}")

Edit model

Model ID terdeteksi otomatis dari server dan tidak bisa ditambah manual. Model berlabel FREE memakai kuota token user, model berlabel PRO/VIP memakai kredit user — token & kredit tidak tercampur. /req = harga flat tiap panggilan (berapa pun panjang jawabannya), /1M = harga per 1 juta token input/output sesuai pemakaian aktual.
Flat per panggilan: 1 prompt masuk + 1 jawaban keluar = 1 harga, tidak tergantung panjang jawaban.
Dihitung dari token prompt yang dikirim.
Dihitung dari token jawaban yang dihasilkan.
Kalau dinonaktifkan, model disembunyikan dari daftar user dan request ke model ini ditolak — walaupun harganya diisi.
